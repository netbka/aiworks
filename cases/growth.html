Growth Farm: агентство на ИИ-агентах

Growth Farm — маркетинговое агентство для наших продуктов, где сотрудники — ИИ-агенты. Здесь нет кода для людей: агенты исследуют рынок, ищут площадки, пишут и проверяют тексты и ведут гипотезы. Цель — деньги, а не число постов.

Из чего состоит

  • Где рождается задачаПлан волны на две недели: гипотезы с метрикой и правилом остановки, задачи по каждой.
  • Чем работают агентыПоиск и браузер, почтовые черновики, API площадок для публикации, база гипотез и реестр фактов о продуктах.
  • Что на выходеПроверенный текст на площадке, отчёт об исследовании, итог гипотезы по её метрике.

Как идёт волна

  1. Подключение. Репозиторий агентства подключён к AIWorks как проект. Задачи волны — обычные задачи в трекере GitHub, AIWorks выполняет их и пишет отчёт прямо туда.
  2. Гипотезы до запуска. Каждую записывают с прогнозом, метрикой и правилом остановки. Вывод проверяет отдельный агент-скептик, а не автор.
  3. Тексты. Три разных агента пишут по одному брифу независимо. Редактор выбирает версию, сверяет факты и правила площадки и закрепляет точный текст.
  4. Выпуск без владельца. Утверждённый текст агент публикует сам — через API или последним кликом в браузере — и собирает замеры через сутки, двое и неделю.

Что здесь особенного для AIWorks

  • Несколько агентов по очереди. Одинаковые задачи распределяются между Claude, Gemini и Codex. По каждому результату видно, кто его сделал, сколько токенов ушло и прошёл ли он проверку. Получается живое сравнение агентов на реальной работе.
  • Проверяющий ловит цифры. В первой волне он дважды вернул отчёт об исследовании из-за неверных чисел. План волны прошёл с первого раза.
  • Человек — не узкое место. Владелец смотрит один утренний пакет: письма, которые нужно отправить от его имени, и решения о деньгах.
