How work runs

After you start a goal, AIWorks splits it into steps, builds, checks independently, fixes what the check finds and continues after crashes and usage limits. It comes back to you before it changes what the goal includes, its criteria, its budget, client data or the release.

Release

Manual: you press PublishOn
Automatic release
Publishes a checked version without waiting for you, only under rules you set
Setting up shows where it publishes, which changes are allowed, which checks are required, who is told and what can be restored.
