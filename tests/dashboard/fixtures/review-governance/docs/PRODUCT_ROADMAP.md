# Example product roadmap

A made-up roadmap for the review dashboard (tests/dashboard/fixtures/review-store.mjs). It replaces the test copy of
Engineering Platform's roadmap, so a reviewer sees no real project.

The dashboard reads `### P<n> - title` and `### R<n> - title` headings here and names Engineering Platform as their
repository and source. This file has none of those headings, so the review dashboard lists no platform roadmap items.

- example/shop-app: search filters, then a sale banner.
- example/recipes: unit conversion and printing.
- example/notes-site: link checks and a dark theme.
